# 结果记录

这里目前没有模型成绩。`template.json` 是未填写的空表，不是一次测试结果。

复制模板，为每次独立运行单独记录。`scores` 的键和上限必须与
`../benchmark.json` 一致；未测的值用 `null`。仅当完成评分时使用
`status: "completed"` 并填写总分。

公开提交前检查隐私。不要提交访问令牌、私人账号、公司内网地址、
完整私密聊天或未经授权的候选代码；模型供应商、公开版本名、测试配置
和获准公开的摘要足以支撑比较。

验证已完成的记录：`npm run verify-run -- results/example.json`。
